# Retail Sales Interactive Dashboard using Tableau & Power BI

This project focuses on designing and developing an interactive Business Intelligence dashboard using Tableau and Power BI to analyze a Retail Sales dataset. The dashboard enables dynamic data exploration by allowing users to filter, drill down, and interact with the data to gain meaningful insights. The dataset includes fields such as Order Date, Region, Product Category, Sales, Profit, and Quantity. During the project, the data was cleaned, transformed, and organized by handling missing values, ensuring correct data types, and creating calculated fields such as Profit Margin. Interactive features including filters, slicers, tooltips, drill-down functionality, and parameter controls were implemented to improve user experience and make data analysis more efficient. The dashboard consists of KPI cards for Total Sales, Total Profit, Total Quantity, and Profit Margin, along with a line chart for sales trends, a side-by-side bar chart for category-wise sales comparison, a symbol map for regional sales analysis, and a pie chart showing the sales distribution across product categories. These visualizations help users identify sales trends, compare regional performance, evaluate product categories, and make data-driven business decisions. Overall, this project demonstrates the effective use of Tableau and Power BI to transform raw retail sales data into an interactive dashboard that supports better analysis, reporting, and decision-making.
